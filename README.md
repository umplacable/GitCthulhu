# GitCthulhu

## Instalation
Pour installer les dépendances de l'app, il faudra d'abort installer NodeJS pour pouvoir utilier les commandes `npm`. Sur le site Web : https://nodejs.org/fr/download. 
Après avoir instaler NodeJS, il va faloir installer les dépendances du projet : 
``` shell
npm install
```

## Lancement de L'application
Pour lancer l'application il faudra lancer la commande : 
``` shell
npm start
```
ou
``` shell
electron .
```
